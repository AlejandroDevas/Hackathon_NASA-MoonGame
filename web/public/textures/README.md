# Earth texture

- File: `earth.jpg` (2048 x 1024, equirectangular, about 270 KB).
- Source: NASA Earth Observatory, **Blue Marble: Next Generation**, base map, January 2004, `world.200401.3x5400x2700.jpg` (5400 x 2700, 1,884,678 bytes), from [science.nasa.gov](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/). Data produced by Reto Stöckli, NASA Earth Observatory (NASA Goddard Space Flight Center).
- Credit, as NASA asks: "NASA Earth Observatory". NASA does not endorse this project; usage follows the NASA Images and Media Usage Guidelines (the page states no separate license).
- Changes made here: resized to 2048 x 1024 (Lanczos), and the deep ocean, which the source leaves a flat near-black blue because the base map has no bathymetry, was recoloured to a blue that fades back to the original colours at the coasts. Land, snow and ice are NASA's pixels.
- The source has no clouds. The cloud layer in the scene is procedural, drawn on a second sphere.
- While the image loads, or if it cannot load, the scene uses a procedural Earth instead.
